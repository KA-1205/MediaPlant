# 🌿 MediPlant AI

**An End-to-End Fine-Grained Visual Classification and RAG Knowledge System for Indian Medicinal Plants**

## 📖 Abstract
MediPlant AI is a production-grade machine learning pipeline designed to identify 80 species of Indian medicinal plant leaves from images. It utilizes a heterogeneous deep learning ensemble—combining the global hierarchical attention of a Swin Transformer with the local textural feature extraction of ConvNeXt. To ensure safety and mitigate medical hallucinations, the classification engine is paired with a Retrieval-Augmented Generation (RAG) pipeline powered by Gemini 2.5 Flash, which grounds all generated Ayurvedic insights in a verified, local knowledge base.

## 🚀 Key Contributions
* **High-Accuracy Classification:** Achieved a **98.26%** test accuracy using a mathematically stable weighted average ensemble on base models, outperforming individual architectures.
* **Medical Safety via RAG:** Engineered a strict RAG pipeline that prevents the LLM from generating unverified medical advice. The system strictly references classical Ayurvedic texts and verified pharmacological data (`plant_kb.json`) before generation.
* **Distribution Mismatch Resolution:** Conducted extensive K-Fold stacking experiments. Identified and resolved a severe logit distribution shift caused by "Model Soup" averaging, successfully engineering a leak-free meta-classifier using strict Out-Of-Fold (OOF) logits.

## 🔬 Architecture
The system is bifurcated into two primary stages: Vision and Knowledge.

### 1. The Vision Ensemble (PyTorch + timm)
* **Branch A: Swin Transformer Tiny** captures the macro-structure of the leaf (shape, venation, spatial layout) via shifted-window attention. (Individual Accuracy: 98.07%)
* **Branch B: ConvNeXt Tiny** acts as a modernized CNN to capture micro-textures (surface detail, fine edge sharpness, disease spots). (Individual Accuracy: 96.91%)
* **Production Combiner:** A weighted average ensemble (`0.502 / 0.497`) resolves disagreements between the branches without adding computational overhead during inference.

### 2. The Knowledge Pipeline (Gemini 2.5 Flash)
Once the plant is classified, the system executes a 4-step pipeline:
1. **Retrieve:** Queries a verified local database containing active compounds, Ayush references, and contraindications.
2. **Augment:** Injects these facts into the LLM prompt as immutable ground truth.
3. **Generate:** Gemini 2.5 Flash expands on the data at a strict `temperature=0.1` to prevent creative hallucination.
4. **Validate:** Cross-references the generated scientific nomenclature with the local database to flag inconsistencies.

## 📊 Research Finding: The K-Fold Distribution Mismatch

During development, a meta-classifier (Learned Stacking) was implemented to optimize ensemble weights. Initial K-Fold validation revealed a critical engineering trap:

When the meta-classifier was fed logits from **"Model Soups"** (base models whose weights were averaged across 5 folds), the test accuracy crashed to **94.40%**. 

**The Diagnosis:** Averaging the weights of the base models fundamentally shifted the probability distributions of the logits at test time compared to what the meta-classifier saw during training. 

**The Resolution:** The pipeline was re-architected to train the meta-classifier strictly on **Out-Of-Fold (OOF)** logits generated by the individual fold models. This eliminated the data leakage and aligned the training/test distributions, causing the stacking performance to rebound to a scientifically rigorous **97.87%**.

### Final Performance Matrix

| Model / Strategy | Combiner Methodology | Test Accuracy | F1 Macro |
| :--- | :--- | :--- | :--- |
| Swin Transformer | Single-Run Base Model | 98.07% | 98.07% |
| ConvNeXt | Single-Run Base Model | 96.91% | 97.08% |
| **Weighted Average** | **Base Logits (Production Default)** | **98.26%** | **98.28%** |
| Learned Stacking | OOF Meta-Classifier (Research Fix) | 97.87% | 98.00% |

## 💻 Quick Start & Reproducibility

### Prerequisites
* Python 3.13+
* NVIDIA GPU (Tested on RTX 3050 4GB)
* Gemini API Key

### Installation
```bash
git clone https://github.com/KA-1205/mediaplant-ai.git
cd mediaplant-ai
pip install -r requirements.txt
```

### Environment Setup
Create a `.env` file in the root directory and add your Google Gemini API key:
```bash
GEMINI_API_KEY=your_api_key_here
```

### Reproduce Paper Metrics
To regenerate the performance tables, confusion matrices, and metrics locally:
```bash
python scripts/evaluate.py
```

### Launch the App
To interact with the identification model and the RAG pipeline:
```bash
streamlit run app/app.py
```
